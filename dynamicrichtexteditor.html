FAQ

Frequently Asked Questions (FAQs)

1. Is DRTE a standalone application?

No, DRTE is a 100% Salesforce-native tool. This means it is built directly on the Salesforce platform and operates within your existing environment, without the need for complex external integrations.

2. How does the document generation feature work?

DRTE allows you to dynamically generate documents by pulling data directly from Salesforce records, such as an Account or Opportunity. This automates the process of creating professional documents like proposals and contracts.

3. What types of documents can be generated with the editor?

The editor can generate a variety of documents, such as Quotes, Orders, Invoices, and more. It allows for the customization and branding of each document to ensure consistency with your company’s visual identity.

4. Can I use the DRTE for any Salesforce object?

Yes, the DRTE can be used for any standard or custom Salesforce object. You can configure the editor to generate documents for different objects, ensuring that all your documents adhere to your company’s branding guidelines.

5. What customization options are available for the generated documents?

The editor allows you to customize both the dynamic content pulled from Salesforce and any static HTML content you add. You can apply custom styles, colors, and logos to ensure the documents reflect your company’s branding accurately.

6. Can I control the order in which documents are signed?

Yes. The solution supports a sequential e-signature workflow. You can set a specific signing order, ensuring, for example, that an internal team member signs before the document is sent to the client.

7. How do I configure the editor for different object types?

To configure the editor for different object types, you simply need to set up the appropriate template IDs and customize the editor settings. This allows you to generate documents for various record types while maintaining consistent branding across all documents.

8. Can I revert to default settings if needed?

Yes, you can revert to default settings by adjusting the configuration options in the editor or removing custom templates. This flexibility ensures that you can easily switch back to default settings if your branding needs change.

9. How can I ensure that my documents are consistently branded?

To ensure consistent branding, configure the editor with your company’s colors, logos, and fonts. Apply these settings across all your templates and documents to maintain a unified look and feel that aligns with your company’s branding guidelines.

10. What kind of security features are included with the e-signature?

For security and compliance, the final signed document is validated with a timestamp and the signer's IP address is captured on the record. This creates a secure and verifiable audit trail.

11. Does the client need to download software to sign the document?

No, the client receives a secure email link that takes them directly to the e-signature tool. The process is seamless and secure, and they do not need to download or install any external software.
